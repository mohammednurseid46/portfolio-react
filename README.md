# Mohammednur Seid · Portfolio

Modern personal portfolio built with **React 19, Vite, Tailwind CSS 4 and Framer Motion**.

## Run it (VS Code terminal)

```bash
npm install
npm run dev
```

Open the local URL it prints (usually http://localhost:5173).

Build for production: `npm run build` (output in `dist/`), preview it with `npm run preview`.

## Features

- **Command palette**: press `Ctrl K` (`⌘ K` on Mac) to jump to sections, open projects, switch theme/accent/background or copy the email.
- **Interactive canvas background** (Constellation, Neural network, Minimal) that reacts to the mouse.
- **3D tilt cards** with a cursor spotlight, animated counters, scroll progress bar, project filters.
- **Dark / light theme and 4 accent colours**, saved in the browser.
- Contact form opens the visitor's email app pre-filled (no backend needed).
- Respects `prefers-reduced-motion`; fully responsive.

## Edit your content

Everything (text, skills, services, projects, links) is in `src/data.js`.
