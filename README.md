# Mohammednur Seid — Portfolio (React + Vite)

## Run locally
```bash
npm install
npm run dev        # http://localhost:5173
```

## Build
```bash
npm run build      # outputs to dist/
npm run preview
```

## Deploy to GitHub Pages
Option A: push to `main` and enable **Settings → Pages → Source: GitHub Actions** (workflow included).
Option B: `npm run deploy` (publishes `dist` to the `gh-pages` branch; set Pages source to that branch).

## Edit content
Projects, skills and contact details are in `src/data.js`. Styles are in `src/styles.css`.
